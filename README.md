# سایت رزومه عسل

یک Portfolio فارسی و راست‌چین با طراحی مینیمال، لوکس و رنگ‌بندی سرمه‌ای، سفید و کرم.

## تکنولوژی‌ها
- HTML5
- CSS3
- Vanilla JavaScript

## اجرا
فایل `index.html` را با VS Code باز کن و با افزونه Live Server اجرا کن.

## فایل‌ها
- `index.html` ساختار اصلی سایت
- `style.css` طراحی و Responsive
- `script.js` منوی موبایل و انیمیشن‌ها
- `assets/` محل تصاویر و فایل‌های جانبی
